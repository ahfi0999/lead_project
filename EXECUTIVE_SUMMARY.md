## 💼 Business Impact

### Expected ROI
- ⬆️ **Improved Conversion Rates** - Focus on high-probability leads (≥80% score)
- ⚡ **Enhanced Sales Efficiency** - Automated lead qualification process
- 💰 **Cost Reduction** - Optimize resource allocation and reduce wasted effort
- 📈 **Scalability** - Handle increasing lead volumes without proportional staff increase

### Lead Classification
- 🔥 **HOT LEADS (≥80%):** Immediate phone call
- ⚠️ **WARM LEADS (50-79%):** Email follow-up
- ❄️ **COLD LEADS (<50%):** Nurturing list

---

## 🛠️ Technical Highlights

- **Machine Learning:** Logistic Regression for binary classification
- **Web Framework:** Streamlit for interactive user interface
- **Data Processing:** Pandas & NumPy for efficient data handling
- **Feature Engineering:** One-hot encoding + StandardScaler normalization
- **Model Persistence:** Joblib serialization for deployment

## 📊 Input Features

The model analyzes 8 key factors:

1. **Time Spent on Website** - Engagement indicator
2. **Total Visits** - Interest level measurement
3. **Page Views Per Visit** - Content consumption depth
4. **Occupation** - Demographic segmentation
5. **Lead Source** - Marketing channel effectiveness
6. **City** - Geographic targeting
7. **Last Activity** - Recent engagement type
8. **Sales Tags** - Current lead status
